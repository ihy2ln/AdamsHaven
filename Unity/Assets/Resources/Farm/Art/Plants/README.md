# Farm flora sprites

These transparent PNGs are separated from the four supplied plant sheets. Each
file is trimmed to the visible illustration and can be placed independently in
the farm scene. `flora_sheet01` contains the cleanest single-plant set; the
later sheets add flowers, grasses, mushrooms, shrubs, and small trees.

The source sheets are retained outside the Unity project. Re-run
`Tools/split_plant_sheets.py` if a fresh separation is needed.
